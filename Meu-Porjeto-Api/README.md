# Meu-Porjeto-Api

Projeto demo: Next.js + tRPC + Drizzle (SQLite) com layout responsivo (Tailwind).

## Instalação (npm)
1. `npm install`
2. `npm run seed`
3. `npm run dev`

Acesse: http://localhost:3000

## Deploy sugerido
1. Suba o repositório no GitHub.
2. Importe o repo no Vercel e rode o deploy.
3. Conecte o domínio: https://api.danielgomes.dev
